📘 DevOps Demo — Projeto Didático

Este projeto foi criado para fins educacionais, com foco em:

Colaboração usando Git Flow

Abertura de Pull Requests

Aplicação de um checklist de auditoria

Organização do repositório seguindo boas práticas

Cada integrante do grupo deve criar uma feature, fazer uma alteração simples e abrir um PR seguindo o checklist padronizado.

🧩 Tecnologias Utilizadas

Node.js

NPM

Git + Git Flow

GitHub
